### ✅ 기획 배경

> 조회수를 늘리는 접근만으로는 매출이 늘지 않았다

째깍섬 방문 리뷰(네이버 블로그, 2023~2026, 최종 191건)와 보호자 심층 인터뷰 5명을 분석한 결과, "무엇을 하는 프로그램인지 미리 알기 어렵다", "지난번과 똑같아 보여 재구매하지 않았다"는 불만이 반복됐다. 6개월치 8개 센터 데이터를 함께 보면 신규 유입이 많은 센터일수록 오히려 재방문율이 낮았고, 반복 이용(돌봄형) 센터가 매출 상위권을 차지했다. 원인은 콘텐츠 자체가 아니라 **"정보가 충분히 전달되지 않는 것"**이라는 결론을 내렸다.

### ✅ 서비스 소개

> **상세페이지 개선 가설 5개를 AS-IS/TO-BE 화면으로 만들어 실제 사용자 투표(1인 1표)로 검증한 UX 개선 프로젝트**

- 프로그램 진행 순서 타임라인, UX 라이팅, 재방문 알림, 선생님 프로필, 편의시설 안내 — 5가지 개선 가설 도출
- 각 가설을 AS-IS/TO-BE 화면으로 제작해 익명 투표 사이트에 배포, 실시간 집계
- 투표 종료 후 결과를 정리한 포트폴리오용 정적 사이트로 재구성

### 👥 서비스 대상

- 째깍섬 잠실센터 앱 가입 부모 중 재구매로 이어지지 않은 대상 (1차 타겟)
- 미취학 아동 자녀를 둔 보호자 (인터뷰 표본 기준 39개월~7세)

## 💌 테스트 항목 및 최종 결과

| UC | 가설 | 결과 |
| --- | --- | --- |
| UC1 · 프로그램 타임라인 | 수업 시간을 세분화해 보여주면 활동 흐름을 몰라 예약을 포기하던 부모가 예약한다 | **TO-BE 87%** (26/30표) |
| UC2 · 행동 동사 UX Writing | 카피에 '아이 행동 동사'를 넣으면 회차 간 차이를 인식한다 | AS-IS 58% (15/26표) |
| UC3 · Alert Bottom Sheet | 지난 회차의 차이를 명시하면 재방문 부모의 "같은 거네" 판단이 줄어든다 | **TO-BE 87%** (21/24표) |
| UC4 · 선생님 프로필 | 선생님 이력·안전 교육 명시가 신뢰 가산점으로 작동한다 | **TO-BE 100%** (24/24표) |
| UC5 · 부모 편의시설 | 구비된 편의 시설을 초기 화면에서 한눈에 확인해 피로도를 줄여준다 | **TO-BE 96%** (24/25표) |

총 5개 항목, 누적 129표 집계(한 명이 여러 UC에 중복 투표 가능해 총 참여 인원과는 다름). **UC2를 제외한 4개 항목에서 TO-BE(개선안)가 채택**되어 실제 상세페이지에 반영했다.

`(AS-IS/TO-BE 비교 화면 스크린샷 추가 예정 — 이미지/thumbs/ 폴더 참고)`

## 🔍 문제 정의 (5 Whys)

1. **왜 재방문이 낮을까** — 부모가 새 프로그램을 봐도 "또 같은 거네"라 지각하고 예약하지 않는다
2. **왜 같다고 지각할까** — 부모가 판단할 수 있는 정보가 주제·사진·가격뿐이다
3. **실제로는 뭐가 다를까** — 프로그램은 체험 방식에서 서로 다르다 (아이는 몸으로 하는 행동으로 새로움을 판단)
4. **왜 그 차이가 전달되지 않을까** — 부모는 아이의 판단 기준을 대신 읽어줄 근거가 없다
5. **왜 앱에 그 근거가 없을까** — 프로그램의 체험 방식·활동 흐름·결과물 정보가 상세페이지에 없기 때문 → **정보 설계로 문제를 풀기로 결정**

## 📖 보는 방법

`index.html`을 열면 `째깍섬_결과보고서.html`(결과 요약 페이지)로 이동한다.
각 카드를 누르면 해당 UC의 AS-IS/TO-BE 비교 화면과 최종 투표 결과(`uc*-result.html`)를 볼 수 있다.

```
└─📦 tictoccroc-ab-progress
  ├─📜 index.html                  # 째깍섬_결과보고서.html로 리다이렉트
  ├─📜 째깍섬_결과보고서.html         # 케이스 스터디 (팀·진행과정·배경·목표·UC 5개 최종 결과·기대 효과)
  ├─📜 uc1-result.html ~ uc5-result.html   # UC별 비교 화면 + 최종 결과 (정적)
  ├─📂 이미지/                      # UC별 AS-IS/TO-BE 스크린샷, 로고
  ├─📂 글꼴/                        # Pretendard 폰트 파일
  │
  ├─📜 ab-progress.html            ┐
  ├─📜 uc1-compare.html ~ uc5-compare.html  │  투표 당시 원본 페이지 (아카이브, Firebase 실시간 투표 UI 포함)
  ├─📜 vote.js                     │
  └─📜 firebase-config.js          ┘
```

## 📈 기대 효과

핵심 목표는 상세페이지 UX 개선을 통한 **재구매율(Retention) 개선**이다. 사내 매출·재구매율 정량 수치는 민감 정보로 공개 범위에서 제외했고, 이후 추적하기로 한 지표만 남긴다.

- 핵심 지표 : 재구매율(Retention)
- 2차 지표 : 상세 → 예약 클릭률 / 탐색 후 미구매 이탈률 / 상세페이지 탐색 시간
- Counter metric : 객단가 / "안내와 실제가 달랐다" 언급률
