Motion & State

동작과 접근성

Open / Close

전환

  • 열림 — sheet translateY(100%) → 0, backdrop opacity 0 → 1, 200ms ease-out. 토큰 transitionDuration 기본값 그대로.
  • 닫힘 수단 3가지 — 핸들 아래로 드래그(enableDragCloseHandler), Backdrop 탭, 텍스트 버튼. 안드로이드 백 제스처도 onClose로 연결.
  • 드래그 임계값 — 시트 높이의 25% 또는 속도 0.5px/ms 초과 시 닫힘, 미달 시 원위치 스프링.
  • reduced-motion — 슬라이드 제거, 페이드만 200ms.
A11y

접근성

  • role — dialog + aria-modal="true", 타이틀을 aria-labelledby로 연결.
  • 포커스 — 열릴 때 타이틀로 이동, 시트 내부 포커스 트랩, 닫힐 때 트리거 요소로 복귀.
  • 터치 타겟 — 모든 버튼 최소 48px 높이 확보(현재 52 / 48).
  • 대비 — #FFC800 위 텍스트는 grey.100만 사용. 흰 텍스트는 대비 미달이라 금지.

CTA

버튼은 눌렀을 때 벌어지는 일 그대로

OK쿠폰 받고 수업 보기 — 결과가 두 개면 두 개 다 쓴다
NO확인 / 자세히 보기 — 무엇이 일어나는지 없음
OK다음에 볼게요 — 거절도 사용자 어투로
NO혜택 포기하기 — 죄책감 유도(컨펌셰이밍) 금지
아이 이름 사용 원칙 — 등록된 아이가 1명일 때만 이름을 노출하고, 2명 이상이면 “아이들이 자주 듣던 수업”으로 대체합니다. 이름이 비어 있을 때의 폴백 카피를 항상 함께 정의하세요.
Gaps

토큰에 없어 임의로 정한 값

아래 5개는 ticticcroc-design-tokens.json에 정의가 없어 이 와이어프레임에서 제안한 값입니다. 확정 전에 검토가 필요합니다.

  • 시트 상단 radius 20px — BottomSheet 토큰에 radius 항목이 없습니다. Dialog와 값을 맞출지 별도로 둘지 결정 필요.
  • 드래그 핸들 40×4 / grey.30 — 크기·색 정의 없음. enableDragCloseHandler가 켜졌을 때의 기본 형태를 스펙에 추가 권장.
  • 시트 최대 높이 90dvh — Dialog에는 maxHeight 438이 있지만 BottomSheet에는 없습니다. 콘텐츠 초과 시 Content 슬롯만 스크롤.
  • 본문 line-height 1.5 — 토큰 기본은 전 스케일 1.2입니다. 2줄 이상 본문에서는 1.2가 붙어 읽히므로 body 스케일에 한해 1.5 옵션 추가 제안.
  • 쿠폰 금액 34px — display d4(40px)는 360 폭에서 줄바꿈이 나고 headline h0(36px)도 빠듯합니다. 금액 전용 크기 정의 또는 d4 축소 사용 규칙 필요.
